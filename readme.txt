A free WordPress restaurant theme for fine dining venues, cafés, and bistros, with menu layouts, testimonials, and table reservations.

== Description ==

DineCraft is a [free WordPress restaurant theme](https://www.createswowtech.com/themes/dinecraft-restaurant-wordpress-theme) built for venues that want their website to feel as considered as their menu. If you run a fine dining room, a café, a steakhouse, a sushi bar, a bakery, or a hotel restaurant, DineCraft gives you a complete restaurant website without hiring a designer or keeping a developer on retainer.

Because bookings matter more than page views, DineCraft doubles as a restaurant booking theme. A reservation page template sits alongside your menu presentation, chef story, and guest testimonials, so browsing turns into a booked table. Dedicated page templates cover your menu, about, booking, contact, and blog pages, and every layout stays fast and fully responsive on phones, tablets, and desktops.

Download the theme, view the live demo, and read the full documentation on the official product page:
https://www.createswowtech.com/themes/dinecraft-restaurant-wordpress-theme

= Benefits =

* Turns visitors into bookings. The reservation template and repeated call-to-action sections keep table booking one click away from every page.
* Loads fast. System font stacks, no remote font requests, explicit image dimensions, and optimized queries keep Core Web Vitals healthy and reduce layout shift.
* Respects guest privacy. There are no third-party embeds or tracking scripts. The location section uses a plain directions link instead of an embedded map iframe.
* Accessible by default. A skip link, keyboard-friendly navigation, ARIA labels, and screen-reader text are built in.
* Safe to extend. All output is escaped and all Customizer input is sanitized.
* Easy to hand over. Your client edits the restaurant name, hero copy, hours, contact details, and social links from the Customizer without touching code.

= Companion Plugin =

DineCraft follows the WordPress theme review guideline that content and functionality belong in plugins, not themes. The optional DineCraft Core companion plugin adds the banners, menu items, menu categories, testimonials, reservations, and contact message post types that the theme templates display. The theme works without it, falling back to bundled placeholder content, and an admin notice points you to the plugin when it is not active.

Form processing is also plugin territory. Add a form block or shortcode from your preferred form plugin, or activate the companion plugin, to make the Book and Contact pages accept submissions.

== Installation ==

= Install From the WordPress Admin =

1. Download the theme ZIP from https://www.createswowtech.com/themes/dinecraft-restaurant-wordpress-theme
2. In WordPress, go to Appearance → Themes → Add New → Upload Theme.
3. Choose the ZIP file and click Install Now.
4. Click Activate.

= Install Manually Over FTP =

1. Unzip the theme archive on your computer.
2. Upload the `dinecraft` folder to `/wp-content/themes/` on your server.
3. In WordPress, go to Appearance → Themes and activate DineCraft.

Keep the folder named `dinecraft` so the folder slug matches the text domain used for translations.

== Setup Guide ==

1. Activate the optional DineCraft Core companion plugin to unlock banners, menu items, testimonials, reservations, and contact messages.
2. Create your pages: Menu, Book a Table, About, Contact, and Blog.
3. Assign the matching page template to each one from the Page Attributes → Template dropdown in the page editor.
4. Under Settings → Reading, set a static front page and choose your Blog page as the posts page.
5. Go to Appearance → Menus, build your navigation, and assign it to the Primary and Footer menu locations.
6. Go to Appearance → Customize → Restaurant Options and fill in the restaurant name, tagline, hero title and subtitle, footer description, address, phone, email, copyright text, map latitude and longitude, and your Instagram, Facebook, and X links.
7. Go to Appearance → Customize → Site Identity to upload your logo, and use the custom header and background options to set your imagery.
8. Add your dishes as menu items, group them with menu categories, and add guest testimonials.
9. Add a form block or shortcode to the Book and Contact pages so submissions are delivered.
10. Optional: add widgets to the Blog Sidebar and Footer Widgets areas under Appearance → Widgets.

== Frequently Asked Questions ==

= Is DineCraft really free? =

Yes. DineCraft is a free WordPress restaurant theme released under the GNU General Public License v2 or later. You can use it on client sites and commercial projects, and you can modify it. Download it at https://www.createswowtech.com/themes/dinecraft-restaurant-wordpress-theme

= Does the theme include contact or reservation processing? =

No. Form processing is plugin functionality under the WordPress.org Theme Directory guidelines. Add a form block or shortcode from your preferred form plugin to the relevant page, or activate the DineCraft Core companion plugin.

= Do I need the companion plugin? =

No, but it is recommended. Without it the theme displays bundled placeholder content. With it you get the banner, menu item, testimonial, reservation, and contact message post types that the templates are built around. Keeping this content in a plugin means it survives if you ever switch themes.

= Can I use DineCraft for a café, bakery, or bar instead of a fine dining restaurant? =

Yes. The layouts, menu presentation, and reservation flow suit any food and drink venue. Change the hero copy, colors, and imagery from the Customizer to match your brand.

= Does the theme work with the block editor? =

Yes. DineCraft supports wide and full alignment, responsive embeds, block styles, and editor styles, and it ships with Reserve a Table and Opening Hours block patterns plus Restaurant Card and Testimonial Quote block styles.

= Does the theme load Google Fonts or embed Google Maps? =

No. DineCraft uses fast system font stacks with no remote font requests, and the location section links out for directions instead of embedding a third-party map iframe. This keeps the theme fast and privacy friendly.

= Is the theme translation ready? =

Yes. All strings use the `dinecraft` text domain and a `dinecraft.pot` template is bundled in the `languages/` folder.

= What should the theme folder be named? =

Use `dinecraft` so the folder slug matches the text domain used for translations.

= Where do I get support? =

Support and customization requests are handled at https://www.createswowtech.com
