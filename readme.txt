An elegant, responsive WordPress theme for restaurants, cafés, and fine dining venues.

== Description ==

Your Restaurant includes an elegant front page, menu presentation, testimonials, reservation and contact page templates, blog templates, block patterns, accessible navigation, and Customizer options. The reservation and contact templates display page content, making them compatible with the form plugin of your choice.

== Installation ==

1. Upload the `your-restaurant` theme folder to `/wp-content/themes/`.
2. Activate Your Restaurant via Appearance → Themes.
3. Create pages and assign the provided page templates (Menu, Book, About, Contact, Blog).
4. Configure branding and contact details under Appearance → Customize.
5. Add form blocks or shortcodes from your preferred form plugin to the Book and Contact pages.

== Frequently Asked Questions ==

= Does the theme include contact or reservation processing? =

No. Form processing is plugin functionality under the WordPress.org Theme Directory guidelines. Add a form block or shortcode from your preferred form plugin to the relevant page.

= What should the theme folder be named? =

Use `your-restaurant` so the folder slug matches the text domain used for translations.
